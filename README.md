# 🌿 PlantCare — вебзастосунок для догляду за рослинами

**PlantCare** — вебзастосунок, розроблений на Django, який допомагає користувачам організовувати догляд за кімнатними рослинами, планувати завдання та відстежувати історію їх виконання.

Проєкт створений як фінальна робота з курсу Python (додатково Django).

## ✨ Можливості

- **Реєстрація та авторизація** — створення облікового запису, вхід і вихід із системи.
- **Особиста колекція рослин** — додавання, перегляд, редагування та видалення рослин.
- **Фотографії рослин** — завантаження власних зображень із відображенням стандартної ілюстрації, якщо фото відсутнє.
- **Пошук рослин** — пошук за назвою або видом без урахування регістру символів.
- **Планування та керування завданнями** — створення, редагування та видалення завдань із зазначенням типу догляду, дати та пріоритету.
- **Відстеження завдань** — перегляд усіх, невиконаних, виконаних і прострочених завдань.
- **Виконання завдань** — можливість позначати завдання як виконані з автоматичним записом в історію догляду.
- **Автоматичний розрахунок поливу** — визначення дати наступного поливу за встановленим інтервалом.
- **Оновлення інформації про полив** — під час виконання завдання поливу автоматично оновлюється дата останнього поливу рослини.
- **Контроль прострочених поливів** — відображення рослин, які потребують поливу.
- **Історія догляду** — збереження та перегляд інформації про виконані завдання.
- **Статистика** — кількість рослин, виконаних і невиконаних завдань, прострочених поливів.
- **Захист даних** — кожен користувач має доступ лише до власних рослин, завдань та історії догляду.
- **Адаптивний інтерфейс** — зручне використання на комп'ютерах, планшетах і мобільних пристроях.
- **Адміністративна панель** — керування моделями застосунку через Django Admin.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/shevchenkoiryna2018/Final_project.git
cd Final_project
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Локальні налаштування

Створіть файл `plant_care/plant_care/local_settings.py` із таким вмістом:

```python
SECRET_KEY = 'your-generated-secret-key'

DEBUG = True

ALLOWED_HOSTS = [
    '127.0.0.1',
    'localhost',
]
```

Для генерації секретного ключа можна скористатися командою:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Скопіюйте отриманий ключ замість `your-generated-secret-key`.

Файл `local_settings.py` виключений із Git через `.gitignore`, тому секретний ключ і локальні налаштування не публікуються в репозиторії.

### 5. Застосування міграцій

Перейдіть до папки Django-проєкту:

```bash
cd plant_care
python manage.py migrate
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

Відкрийте у браузері:

http://127.0.0.1:8000/

Зареєструйте нового користувача та почніть створювати власну колекцію рослин.

## 📂 Структура проєкту

```text
Final_project/
├── README.md
├── requirements.txt
├── .gitignore
└── plant_care/
    ├── manage.py
    ├── plant_care/       # Налаштування Django
    ├── plants/           # Моделі, форми, представлення, маршрути, адмінпанель
    ├── templates/        # HTML-шаблони

```

Завантажені користувачами фотографії зберігаються локально в папці `media/`, яка не додається до GitHub.

База даних SQLite (`db.sqlite3`) створюється локально після застосування міграцій і також не зберігається в репозиторії.

## 🌱 Основні моделі

**Plant** — інформація про рослину, її власника, фотографію, інтервал поливу, дату останнього поливу та інші характеристики.

**CareTask** — заплановане завдання з догляду, його тип, дата, пріоритет і статус виконання.

**CareLog** — історія догляду за рослинами з датою виконання, типом догляду та примітками, пов'язана з виконаними завданнями за їх наявності.
