# PlantCare — вебзастосунок для догляду за рослинами

**PlantCare** — вебзастосунок, розроблений на Django, який допомагає користувачам організовувати догляд за кімнатними рослинами, вести власну колекцію, планувати завдання, контролювати графік поливу та відстежувати історію догляду.

Проєкт створений як фінальна робота з курсу Python (додатково Django).

## ✨ Можливості

### 👤 Обліковий запис

- Реєстрація, вхід та вихід із системи.
- Особистий кабінет із колекцією рослин, завданнями та історією догляду.
- Обмеження доступу до особистих даних інших користувачів.

### 🪴 Колекція рослин

- Додавання, перегляд, редагування та видалення рослин (CRUD).
- Збереження назви, виду, дати придбання, розташування, інтервалу поливу, дати останнього поливу та приміток.
- Завантаження, заміна та очищення фотографій рослин.
- Відображення стандартної ілюстрації за відсутності фотографії.
- Пошук за назвою або видом рослини без урахування регістру символів.
- Фільтрація рослин із простроченим поливом.
- Сортування за назвою (А–Я, Я–А), датою додавання до колекції (спочатку новіші або старіші) та датою наступного поливу.
- Можливість комбінувати пошук, фільтрацію та сортування.

### 💧 Контроль поливу

Дата наступного поливу автоматично розраховується на основі дати останнього поливу та індивідуального інтервалу поливу рослини.

Для кожної рослини відображається один із п'яти статусів:

| Статус | Значення |
|---|---|
| 🔴 Полив прострочено | Дата наступного поливу вже минула. |
| 🟡 Потрібно полити сьогодні | Наступний полив запланований на сьогодні. |
| 🔵 Наступний полив завтра | Наступний полив запланований на завтра. |
| 🟢 Полив за графіком | Дата наступного поливу пізніше ніж завтра. |
| ⚪ Дату останнього поливу не вказано | Для розрахунку наступного поливу недостатньо даних. |

Після виконання завдання з поливу дата останнього поливу автоматично оновлюється, а дата наступного поливу та статус перераховуються.

### 📋 Завдання з догляду

- Створення, перегляд, редагування та видалення завдань.
- Планування поливу, підживлення, пересадки, обрізки та інших видів догляду.
- Вибір дати виконання та пріоритету завдання.
- Фільтрація: усі, невиконані, прострочені та виконані завдання.
- Позначення завдання як виконаного з автоматичним створенням запису в історії догляду.
- Захист виконаних завдань від редагування та видалення через користувацький інтерфейс.

### 📖 Історія догляду

- Автоматичне збереження інформації про виконані завдання.
- Перегляд історії догляду за власними рослинами із зазначенням типу догляду, дати й часу виконання та приміток.

### 📊 Статистика

На сторінці особистої колекції відображаються п'ять показників:

- Загальна кількість рослин.
- Кількість невиконаних завдань.
- Кількість виконаних завдань.
- Кількість прострочених завдань.
- Кількість рослин із простроченим поливом.

Картки статистики є клікабельними та дозволяють швидко переходити до відповідних списків рослин або завдань. Показники відображають загальну статистику користувача незалежно від поточного пошуку, фільтрації та сортування рослин.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/shevchenkoiryna2018/Final_project.git
cd Final_project
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Активація у Linux / macOS:

```bash
source .venv/bin/activate
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Локальні налаштування

Створіть файл `plant_care/plant_care/local_settings.py` із таким вмістом:

```python
SECRET_KEY = 'your-generated-secret-key'

DEBUG = True

ALLOWED_HOSTS = [
    '127.0.0.1',
    'localhost',
]
```

Для генерації секретного ключа скористайтеся командою:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Скопіюйте отриманий ключ замість `your-generated-secret-key`.

Файл `local_settings.py` виключений із Git через `.gitignore`, тому секретний ключ і локальні налаштування не публікуються в репозиторії.

### 5. Перевірка проєкту та застосування міграцій

Перейдіть до папки Django-проєкту:

```bash
cd plant_care
python manage.py check
python manage.py migrate
```

### 6. Створення адміністратора (необов'язково)

Для доступу до адміністративної панелі створіть суперкористувача:

```bash
python manage.py createsuperuser
```

Вкажіть ім'я користувача, електронну адресу та пароль.

### 7. Запуск сервера

```bash
python manage.py runserver
```

Відкрийте у браузері:

- Вебзастосунок: http://127.0.0.1:8000/
- Адміністративна панель: http://127.0.0.1:8000/admin/

Зареєструйте нового користувача та почніть створювати власну колекцію рослин.

## 🌱 Основні моделі

**Plant** — інформація про рослину, її власника, фотографію, дату придбання, інтервал поливу, дату останнього поливу, розташування та примітки.

**CareTask** — завдання з догляду за конкретною рослиною, його тип, запланована дата, пріоритет, статус виконання та примітки.

**CareLog** — запис історії догляду за рослиною із зазначенням типу догляду, дати й часу виконання, приміток та зв'язку із завданням за його наявності.

### Зв'язки між моделями

- `User → Plant` — один користувач може мати багато рослин.
- `Plant → CareTask` — одна рослина може мати багато завдань.
- `Plant → CareLog` — одна рослина може мати багато записів історії догляду.
- `CareLog → CareTask` — запис історії може бути пов'язаний із виконаним завданням.
