# 🌿 PlantCare — вебзастосунок для догляду за рослинами

**PlantCare** — вебзастосунок, розроблений на Django, який допомагає користувачам організовувати догляд 
за кімнатними рослинами, планувати завдання та відстежувати історію їх виконання.

Проєкт створений як фінальна робота з курсу Python та Django.

## ✨ Можливості

- **Реєстрація та авторизація** — створення облікового запису, вхід і вихід із системи.
- **Особиста колекція рослин** — додавання, перегляд, редагування та видалення рослин.
- **Фотографії рослин** — можливість завантажувати власні зображення рослин із відображенням стандартної ілюстрації, якщо фото відсутнє.
- **Планування та керування завданнями** — створення, редагування та видалення завдань із зазначенням типу догляду, дати та пріоритету.
- **Відстеження завдань** — перегляд усіх, невиконаних, виконаних і прострочених завдань.
- **Автоматичний розрахунок поливу** — визначення дати наступного поливу за встановленим інтервалом.
- **Контроль прострочених поливів** — відображення рослин, які потребують поливу.
- **Історія догляду** — автоматичне збереження інформації про виконані завдання.
- **Статистика** — кількість рослин, виконаних і невиконаних завдань, прострочених поливів.
- **Захист даних** — кожен користувач має доступ лише до власних рослин і завдань.
- **Адаптивний інтерфейс** — зручне використання на комп'ютерах і мобільних пристроях.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/shevchenkoiryna2018/Final_project.git
cd Final_project
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Налаштування SECRET_KEY

Створіть файл `plant_care/plant_care/local_settings.py` із таким вмістом:

```python
SECRET_KEY = 'your-generated-secret-key'
```

Для генерації ключа можна скористатися командою:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Скопіюйте отриманий ключ замість `your-generated-secret-key`.

Файл `local_settings.py` виключений із Git через `.gitignore`.

### 5. Застосування міграцій

Перейдіть до папки Django-проєкту:

```bash
cd plant_care
python manage.py migrate
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

Відкрийте у браузері:

http://127.0.0.1:8000/

Зареєструйте нового користувача та почніть створювати власну колекцію рослин.

## 🌱 Основні моделі

**Plant** — інформація про рослину, її власника, фотографію, інтервал поливу та інші характеристики.

**CareTask** — заплановане завдання з догляду, його тип, дата, пріоритет і статус виконання.

**CareLog** — історія виконаних завдань із датою, типом догляду та примітками.
